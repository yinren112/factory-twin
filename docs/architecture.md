# V2 技术结构

## 运行链路

`index.html → engine.js → factory.js → telemetry.js → app.js`。构建器把脚本和 CSS 内联，输出单一 HTML。图像贴花由 Canvas 2D 在初始化时绘制后上传 GPU，无外部资源。

场景采用米制模型。节点图保留设备 ID 与机械关节；静态部分按材质、设备 ID、阴影/反射开关合并。动态机器人关节、移动物料和车轮保留各自变换。两个可剖切墙体独立保留，随观察位置控制可见性。

## 网格与材质

提供倒角盒、圆柱、圆环、管线和圆角轮廓挤出。机械臂壳体使用自定义轮廓和分层平滑边缘法线。对非均匀缩放使用逆转置法线矩阵，合并静态网格时也采用相同处理。

主着色器包含金属度/粗糙度、GGX 形式高光、程序化环境反射、方向光 PCF 阴影、颜色 ID 选择、低强度发光和透明玻璃。贴花启用 alpha 混合，并修正 mipmap 边缘透明颜色。选择与告警明确排除 ID=0 的环境节点。

## 高画质渲染顺序

1. 2048 × 2048 阴影深度。
2. 半分辨率镜面地面反射，反射相机与正反面绕序同步切换。
3. 主场景颜色和深度；支持时使用 4× MSAA，颜色与深度一同 resolve。
4. 半分辨率屏幕空间环境遮蔽：从深度重建观察坐标，采样位置对齐最近邻纹素中心，双边上采样减少边缘误染。
5. 降采样的亮部提取和分离式模糊。
6. 合成、轻度边缘平滑、色调映射、gamma 输出。

地面另有随设备位置移动的低频接触压暗。反射、遮蔽和微表面高光属于实时近似；没有光线追踪、多次反射或体积光输运。

流畅模式关闭反射、遮蔽、辉光和 MSAA，并使用较低渲染分辨率。冻结仿真且相机、设备与画质均未变化时不重复渲染。窗口大小变化重新分配渲染目标；页面退出释放 GL 资源。

## 拾取和同步

鼠标点击用 GPU 颜色 ID 缓冲拾取实际网格。选择设备后，同步右侧详情、趋势图与地面角标。告警修改 RB-02 的运行状态、灯塔、描边、定位光幕与事件面板；复位恢复原运行/待机状态。该链路不向真实设备发送命令。

数据模拟器是独立可测试模块：固定随机种子，前台有效时间驱动，暂停/后台不积累，不把帧数当产量。功率积分得到累计能耗，输出按节拍累加。

## 运动与限制

机械臂使用两连杆平面逆解，并以末端补偿让工具轴保持向下；夹爪作小幅开合。AGV 使用两段直线和两个半圆连接的闭环，车轮依路径时间旋转。第二台车从充电区驶出后进入同一轨道。

没有真实抓取与物料移交，没有工艺节拍联锁或多车碰撞调度。因此不把“路线连续”描述为“工业级无碰撞控制”。测试中的工具垂向间隙是针对本场景物料最高点的有限几何约束。
