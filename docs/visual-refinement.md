# V2 建模与多角度复查记录

## 复查方法

使用交付的完整离线 HTML，在 Chromium 中实时执行 WebGL 2。浏览器直接输出 PNG，没有用图像生成器、静态背景图或后期拼装模型替代实时场景。每轮保留镜头位置、运行状态、构建 SHA-256、几何检查和浏览器错误记录。

本环境的本地 URL 导航受管理策略限制。预检查实际尝试导航失败后，后续使用新建 about:blank 页面和 Playwright `set_content()`，原样载入完整 HTML。未修改浏览器策略。HTTP 服务可达性另行检测。该加载方式验证成品自身，不应被描述为浏览器 localhost / file URL 已成功验收。

## 第一轮：结构与设备模型重做

实际截图：`screenshots/iterations/round-1/`，6 个镜头。

| 观察到的问题 | 修改 | 复查依据 |
| --- | --- | --- |
| 没有告警时，厂房构件也带橙色描边 | 修复 `alarmId=0` 与未分配设备 ID=0 的错误匹配。选择 / 告警都要求 ID 大于 0 | 总览、反向视角、机械臂近景 |
| 检测拱架底座悬空 | 延长立柱，重定位底板和地脚螺栓 | 机器人及检测架近景 |
| 机械臂外壳偏直棱，轴盖和工具头层次不足 | 重建圆角放样铸件、同心轴盖、内凹螺栓、线束、夹爪、操作吊盒 | 正向与反向近景 |
| 加工舱内部空、输送线缺结构 | 补全导轨、主轴、夹具、冷却管、驱动电机和传感器 | 加工中心近景、总览 |
| 厂房缺少顶部与后排层次 | 增加桥架、线束、通风主管、法兰、吊杆、梁节点、测量工位与周转架 | 反向镜头、总览 |

## 第二轮：连接、接地和可读性

实际截图：`screenshots/iterations/round-2/`，9 个镜头。覆盖总览、机器人正反面、加工中心、封装单元、AGV、俯视、低视点、净景。

| 复查发现 | 修改 |
| --- | --- |
| 贴花文字在缩小时有黑边 | 修正透明纹理的 alpha 混合与 mipmap 边缘颜色处理；透明批次以包围盒中心排序 |
| 输送支架的斜撑两端没有真正接上立柱和横梁 | 按实际端点重新连接 |
| 充电桩体量过大，近景遮住 AGV 主体 | 重建低矮充电底座、触点、供电线，并调整 AGV 默认聚焦方向 |
| 部分载荷与台面有缝隙 | 调整载荷基板高度；为轮胎、支脚与地面保留合理接触位置 |
| 护栏玻璃片缺乏工业真实感 | 改为有框、网格、连接片和地脚螺栓的安全围栏 |
| 车轮没有独立运动 | 拆为动态轮组，添加轮毂、螺栓、圆润胎肩，并随移动转动 |
| 机械臂低姿态夹爪距离物料过近 | 调整平面双连杆目标高度，让工具头始终朝下；另用全周期采样验证间距 |
| 从厂房背面观察时墙面遮挡设备 | 加入随观察位置自动隐藏 / 恢复近侧外墙的剖切展示 |

## 第三轮：接触阴影与渲染复验

实际截图：`screenshots/iterations/round-3/`，6 个镜头；修正后 `round-3-fix/`，3 个近景。

在现有方向光阴影、平面反射、柔和辉光的基础上加入半分辨率屏幕空间环境遮蔽。初次截图在加工中心白色平面上出现不应有的斑驳。逐图比较确认是新增通道问题，而非模型材质设计。

修复方法：深度采用最近邻采样时，视空间位置重建也必须对齐到实际深度纹素中心；同时避免双边权重过小时产生错误归一化。修正后重新查看加工中心、机械臂与 AGV 近景，平面脏斑消除，保留缝隙和接触区域的适度压暗。

## 运动与回归检查

真实模型构建器的自动测试覆盖：铸件顶点 / 法线 / 三角面朝向、非均匀缩放的逆转置法线、模型 ID、墙体剖切恢复、机械臂完整周期、AGV 环线及驶离充电位的连续性、待机停止与告警停止。

机械臂以 0.1 秒间隔采样，覆盖超过一轮运动周期。两台工具头的最低测试高度约 1.9725 米，物料模型最高点 1.8475 米，垂向余量约 0.125 米。这个检查不等于完整工业碰撞检测；它只证明测试姿态下夹爪不会下探穿过物料顶面。

AGV 以 0.1 秒间隔测试 80 秒，覆盖闭环路径及首尾连接。最大单步位移约 0.072 米，未观察到路线接缝处的瞬移。它不是多车避障或交通调度系统。

最终高画质镜头和告警复验记录另见 `visual-final.json` 与 `browser-test-results.json`。最终截图由浏览器直接生成；版本与 SHA 校验信息写入相应 JSON。

## 没有宣称完成的事项

没有做真实工业机械结构设计认证、真实六轴控制器求解、物理抓取 / 工件物料守恒、多车避障、PLC 接入或生产安全评估。渲染为实时近似，并非离线路径追踪。没有用软件渲染器观测到的帧率推断用户实体 GPU 的性能。
