## 实际运行方式与环境限制

测试使用 Node.js 22.16.0、Python Playwright、Chromium 144.0.7559.96、ANGLE / SwiftShader 软件渲染和 Xvfb `DISPLAY=:99`。不是离线效果图，不是生成式图像，也没有后期合成设备或界面。

当前浏览器环境禁止本地 URL 导航。预检查实际尝试失败后，使用新建 about:blank 页面的 `page.set_content()` 原样加载完整离线成品，不修改成品、不修改管理策略。HTTP 资源单独检查可达性和内容一致性。因此，本次证明的是交付 HTML 的实际运行、交互与渲染，**没有把浏览器本地 URL 导航列为已通过项**。

初始高画质渲染开启 HDR 和 4× MSAA。总览几何检查记录 340 个可绘制网格批次、203,256 个场景三角形；阴影、反射和主场景的重复提交不应再次计入独立模型面数。交互回归中会切换流畅模式减少软件渲染等待，截图切回高画质。

## 已复验的功能

初始化与八台设备状态；实时数据推进；暂停冻结；设备面板选择；实际模型的 GPU ID 点击拾取；旋转、缩放、平移、聚焦、俯视与巡航；机械臂及 AGV 动画；运行与待机、模拟离线与恢复；温度告警、标签、计数、曲线、状态灯与定位联动；告警冻结目标机械臂而另一台继续；复位；画质切换；标注显隐；净景模式键盘进入和退出。

1280 × 800 与 390 × 844 检查没有 HTML 横向溢出。窄屏总览相机已后移，避免厂房两侧被初始视野裁切；这不代表实体触屏全流程认证。

## 建模与运动检查

实际构建器生成的顶点、法线和世界矩阵均检查有限值。新增测试覆盖圆角铸件面朝向、正反输入轮廓、非均匀缩放法线、设备 ID 保留、外墙剖切恢复、AGV 待机及驶离充电位。

机械臂以 0.1 秒间隔采样，跨越完整周期。记录工具最低高度约 1.9725 米，最高物料为 1.8475 米；工具朝下方向误差小于 1e-5。这个结果仅验证相关几何约束，不等价于完整碰撞检测或真实抓取。

AGV 连续采样 80 秒、800 步，覆盖轨迹直线、半圆及闭环接缝，最大单步位移约 0.072 米。待机时车体和轮组不推进。没有多车避障调度的测试或承诺。

## 不应外推的结论

没有实体 GPU 的帧率基准，没有多显卡、多浏览器、长时间运行或实体手机兼容性认证。软件渲染环境不代表用户硬件性能，不能据此承诺 60 FPS。

当前为前端案例，未接入真实传感器、PLC 或工业网络。机械模型不是厂商原始 CAD；不会执行生产控制、真实机器人操作或安全联锁。局部几何测试通过不等于全场景任意运动无碰撞。
